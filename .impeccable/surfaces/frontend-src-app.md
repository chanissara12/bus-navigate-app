## Direction contract

THESIS: This app reads like real Bangkok transit signage — trustworthy at a glance, safely readable in outdoor tropical sun. It refuses the generic blue-corporate-SaaS-card-list every transit app defaults to, and refuses to visually impersonate an official BTS/MRT product.

OWN-WORLD: Two-tone system. Indigo (`#3D4EAF` light / `#5566D6` dark) is brand identity — station-plate header, default route badges, nav icons, "ปกติ" status. Teal (`#178F79` light / `#4FB3A9` dark) is reserved exclusively as the "recommended/go" signal — the recommended route's badge, border, tint, and the primary CTA (which always confirms the recommended route, never the brand color). Squircle badges (12px radius for route badges, 10px for the smaller icon-wraps used on the bus-stop list), not circular roundels — deliberately distinct from BTS/MRT's circular badges. Tabular-nums monospace for every distance/time/ETA/GPS reading. Neutral gray for cancelled/inactive in both modes (never a third accent hue). Full light (`#ffffff`) and dark (`#121212`, never pure black) themes, matching component shapes. Focus ring is a fixed neutral (near-black `#10151c` on light, near-white `#EDEBE7` on dark) rather than hue-matched, so it never clashes with either accent. Alert/error banners use a warm dusty red (`#9C4A3F` text / `#FBEDEC` bg light, `#E7B0A7` text / `#2E1A17` bg dark) — a third, purely semantic hue never reused for anything but errors/misboarding. The map's "current position" marker is amber (`#D9A441`), kept identical in both themes (unlike every other accent) because it always carries its own white/dark contrast stroke — a deliberate, confirmed exception, not an oversight.

Shared bottom-nav pattern (used on every full-page screen — trip-planning, bus-stop, recovery, travel-session): three tabs, each a small line-icon (search / map-pin / bus glyph, inline stroke SVG, never emoji) above a 12px label; the active tab gets a rounded-rect tinted pill behind its icon (indigo tint) plus bold weight — never color alone. Nav bar has its own lifted surface background (`#1A1F24` on dark; white with a hairline top border on light) so it reads as a distinct bar, not transparent chrome.

STORY: Arriving at trip results, the rider immediately reads which bus is normal service (indigo), which one is the better option right now (teal — always singular, one row only), and which is unavailable (gray, muted). The CTA visually confirms it is committing to the teal-flagged option. Nothing here claims official/BTS status. The same reading order repeats across the app: the bus-stop list surfaces nearby stops with squircle pin icons and expandable landmark context; the recovery flow leads with a dusty-red alert banner, then the same indigo/teal/gray option hierarchy; the travel-session screen keeps the station-plate header anchored while riding and highlights the alighting stop in teal as the one row that matters right now; the route map card carries the same palette into its legend (line-type indicators grouped in one column, point-type markers in the other).

FIRST VIEWPOINT: Station-plate header (destination name, full-bleed indigo bar, rounded corners, ~92px tall) at top; "เลือกสายรถ" label; stacked route rows (44px squircle badge + headsign + tabular-nums meta + status tag) with 12px gaps; exactly one row visually distinct via teal border + tint + badge. Primary CTA pinned above the bottom nav, full-width, teal, naming the recommended route.

FORM: User-steered hybrid, not a straight roll pick. Concept-seed direction round ran with seed key `0451d3a5` (scope=direction, mode=operate; assigned index 3 = Split-Flap Departure Board). The user redirected to candidate #1 on the grounded list (BTS/MRT Signage System, presented as IMPECCABLE'S PICK) for outdoor-legibility reasons, then fused it live with a separate "Data Dark" exploration built via the redesign-existing-projects skill (tabular-nums, off-black `#121212`, tinted shadows). Final differentiation from literal BTS/MRT branding (squircle badges, non-transit-line hues), the teal-reserved-for-recommended rule, and neutral focus rings were directed by the user across several rounds of comparison in a Design-canvas prototype (artifact 3f34eff7-a123-42b6-9cdb-0833e8a3be1f). The bottom-nav icon system, the alert-banner hue, and the route-map card layout were extended to the rest of the app in the same prototype after the trip-planning screen was locked. A user-pinned decision beats the roll — recorded here per that rule.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

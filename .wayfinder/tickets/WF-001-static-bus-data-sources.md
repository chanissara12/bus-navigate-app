## Question

มีชุดข้อมูลไหนที่ให้ **ลำดับป้ายทั้งสาย** (สาย → ป้ายที่ 1, 2, 3 ...) พร้อมพิกัดและทิศทาง สำหรับกรุงเทพฯ และปริมณฑล ที่นักพัฒนาคนเดียวเอามาใช้ได้จริงและถูกกฎหมาย

## Resolution

**ใช้ฟีด Namtang ของ สนข. กระทรวงคมนาคม** — `https://namtang-api.otp.go.th/download/namtang-gtfs.zip`
ยืนยัน URL เองแล้ว: 41.8 MB, `Content-Type: application/zip`, `Last-Modified: 2026-09-19` (ยังมีคนดูแล)

- 2,068 สาย / 17,078 ป้ายพร้อมพิกัด / 126 agency / มี `stop_sequence` และ `direction_id` 0-1 / ชื่อสองภาษารูปแบบ `"ไทย;English"`
- ชื่อสาย ขสมก. เก็บเป็น **เลขคู่** `ใหม่ (เก่า)` เช่น `3-38 (13)`, `1-12E (107)` — 188 จาก 219 สายมีเลขใหม่ และ 158 สายมีเลขเก่าด้วย จึงแมปเลขเก่ากับเลขใหม่ได้ฟรี (มีเคสเพี้ยนราว 31 สาย เช่น `205 เดิม`, `511 [ท]`)
- ป้ายคนละทิศใช้ `stop_id` คนละตัวและพิกัดต่างกัน จึงมีโอกาสคำนวณฝั่งถนนได้ แตกเป็น WF-003
- **กับดักที่เจอ**: 7,930 จาก 17,078 ป้าย (46%) ชื่อว่า `จุดขึ้นลง;visual stop` เฉยๆ แตกเป็น WF-005 และ `stop_times` เก็บเป็น offset สะสมจาก `00:00:00` ไม่ใช่เวลานาฬิกา (เป็นฟีดแบบ frequency-based)
- **ตัวเลือกอื่นตกรอบหมด**: OSM มีแค่ 638 route relation และ 4,927 ป้าย แถมใช้ ref กลับด้าน `เก่า (ใหม่)` ใช้เติมชื่อและเส้นถนนได้แต่ใช้เป็นลำดับป้ายไม่ได้ / data.go.th ค้างที่ 2022-03-25 ซึ่งก่อนปฏิรูป เลขสายผิดทั้งชุด / TransitFeeds ปิดแล้ว / การ scrape ViaBus, Longdo, ขสมก. เป็นความเสี่ยงด้าน ToS โดยไม่จำเป็น

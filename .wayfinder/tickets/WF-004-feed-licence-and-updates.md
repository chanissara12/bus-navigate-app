## Question

ทั้งโปรเจกต์ตั้งอยู่บนฟีดเดียว ก่อนจะสร้างอะไรทับลงไปต้องรู้ว่ามันยืนอยู่บนอะไร

1. **สัญญาอนุญาตคืออะไรกันแน่** — CC-BY-4.0 ที่เห็นมาจากทะเบียนของ Transitland ไม่ใช่จากไฟล์ LICENSE ในซิป ต้องหาแหล่งที่เป็นทางการจาก สนข. หรือ OTP ว่าอนุญาตให้ใช้ต่อได้จริง และต้องให้เครดิตแบบไหน
2. **อัปเดตบ่อยแค่ไหน** — `feed_version` เป็น `20260919` ซึ่งเป็นวันที่ ดูย้อนหลังได้ไหมว่าปล่อยถี่แค่ไหน มีรูปแบบ URL แบบระบุเวอร์ชันไหม หรือทับไฟล์เดิมตลอด
3. **จะรู้ได้ยังไงว่ามีเวอร์ชันใหม่** — เช็คจาก `Last-Modified` หรือ `ETag` พอไหม
4. **มีหน้าเอกสารหรือช่องทางติดต่อของฟีดนี้ไหม** เผื่อวันหนึ่งมันหาย หรือเจอข้อมูลผิดแล้วอยากแจ้ง
5. **ความเสี่ยงที่ฟีดหายไป** — มี mirror ไหม เก็บสำเนาไว้เองได้ตามสัญญาอนุญาตไหม

เขียนรายงานที่ `.wayfinder/research/feed-licence.md`

## Resolution

**ฟีดนี้ยืนบนพื้นที่มั่นคงพอจะสร้างทับได้ แต่ต้องเก็บสำเนาเอง**

**1. สัญญาอนุญาตยืนยันแล้ว และดีกว่าที่คิด** — CC-BY ไม่ได้มาจาก Transitland อย่างที่สงสัย แต่ **สนข. ประกาศเองที่ `https://namtang-api.otp.go.th/opendata`** ซึ่งเป็นหน้าเดียวกับที่แจกลิงก์ดาวน์โหลดไฟล์นี้ ข้อความคือ "สงวนลิขสิทธิ์โดยสำนักงานนโยบายและแผนการขนส่งและจราจร (สนข.) ภายใต้สัญญาอนุญาตแบบ Creative Commons CC-BY" โดยเลข 4.0 อยู่ในลิงก์ ไม่ได้เขียนเป็นตัวอักษร ส่วน Transitland (`f-th~namtang`) และ Mobility Database (`mdb 1831` ติดธง `is_official=True`) แค่มิเรอร์ข้อความนี้มา — **ข้อควรระวัง**: ไม่มีไฟล์ LICENSE ในซิป ไม่มีหน้า Terms of Use แยก และชุดข้อมูลชื่อ Namtang ที่ `otp.gdcatalog.go.th` เป็นสถิติการใช้แอปคนละสัญญาอนุญาต ไม่ใช่ฟีดนี้

**2. อัปเดตทุกวัน** — Transitland เก็บไว้ 100 เวอร์ชันติดกันตั้งแต่ 2026-06-11 ถึง 2026-09-19 ทุกเวอร์ชัน SHA1 ต่างกัน ขนาดโตจาก 38.8 MB เป็น 41.8 MB ใน 5 สัปดาห์ แปลว่าเนื้อหาเปลี่ยนจริงไม่ใช่แค่ build ใหม่ Internet Archive ยืนยันว่า URL นี้แจกไฟล์มาตั้งแต่ 2022-05-12 (ตอนนั้น 7.9 MB) **แต่ไม่มี URL แบบระบุเวอร์ชันและไม่มี changelog** — ลองทั้ง path ต่อท้ายวันที่ โฟลเดอร์รายวัน และ directory listing ได้ 404/500 หมด สนข. ไม่เก็บประวัติเลย

**3. ตรวจเวอร์ชันใหม่**: มี `Last-Modified` และ `Content-Length` แต่ **ไม่มี `ETag`** และ **conditional GET ใช้ไม่ได้** — `If-Modified-Since` ไม่เคยคืน 304 (ทดสอบทั้ง HEAD และ GET) ส่วน `Accept-Ranges: bytes` ใช้ได้ วิธีที่แนะนำคือ HEAD วันละครั้งแล้วเทียบคู่ `(Last-Modified, Content-Length)` **แต่ค่านี้เปลี่ยนทุกคืนไม่ว่าข้อมูลจะเปลี่ยนจริงหรือไม่** จึงควรใช้เป็นตัวจุดชนวนให้ไป diff ของจริง ไม่ใช่ใช้สั่ง import ใหม่ตรงๆ

**4. เอกสารและช่องทางติดต่อแทบไม่มี** — `/api`, `/docs`, `/swagger` 404 หมด มีแค่หน้า `/opendata` ย่อหน้าเดียว ช่องทางติดต่อเดียวที่ประกาศไว้คือ Facebook Messenger `https://m.me/namtangugoweguide` ไม่มีอีเมล **เจอโดยบังเอิญ: `feed_publisher_url` ใน `feed_info.txt` พิมพ์ผิดเป็น `namntang.otp.go.th` ซึ่ง DNS ไม่ติด** — อย่าเอาฟิลด์นี้ไปแสดงเป็นเครดิตอัตโนมัติ

**5. ความเสี่ยงที่ฟีดหาย: เป็นจุดตายจุดเดียว แต่กันได้ทั้งหมด** — CC-BY 4.0 อนุญาตให้ทำสำเนาและเผยแพร่ซ้ำได้ชัดเจน จึงเก็บสำเนาเองได้แน่นอน มิเรอร์ที่มีอยู่เก่าหมด: Mobility Database ค้างที่ 2026-06-04 (ช้ากว่า 3 เดือนครึ่ง), Internet Archive มีซิปแค่ 3 ครั้งใน 4 ปี, Transitland มีประวัติดีที่สุดแต่ต้องมีบัญชีถึงจะโหลดย้อนหลังได้

**สิ่งที่ต้องทำต่อ**: เก็บสำเนาหน้า `/opendata` พร้อมวันที่ไว้เป็นหลักฐานสัญญาอนุญาต และเก็บสำเนาฟีดเองทุกครั้งที่ import

**คำถามที่โผล่ใหม่**: `stop_id` และ `route_id` นิ่งข้ามเวอร์ชันไหม ตอบไม่ได้เพราะมีอยู่เวอร์ชันเดียว แต่ตอบได้ทันทีโดยเอา capture ของ Internet Archive วันที่ 2026-08-13 มา diff กับของปัจจุบัน แตกเป็น WF-011
